# 给新任务的交接入口

日常协作请先读[交接速查](日常交接速查.md)。换机或重新安装请读[安装与默认权限](换机安装与默认权限.md)。首次建立 Claude 协作主会话时，另读[目录核验](新会话目录核验.md)。

可以直接把下面这段发给 ACI 等项目的主任务：

> 本项目使用已安装的 GPT ↔ Claude 通信 MCP 协作；需要独立侧栏子任务时，再使用 Local Card Bridge Desktop。先阅读桥接仓库的 `docs/日常交接速查.md`，检查本项目授权和两端实际会话身份，复用对应的 Claude 协作主会话。通过 MCP 派发目标明确、文件范围清楚的任务；保留消息和卡片编号，超时按同一回执继续等，不重复派发。收到完整结果并核验后再报告完成。需要点卡片时显示对应主会话，通信本身不要求切换窗口。不要开启 Remote Control。遇到缺失的项目授权或宿主拒绝，说明具体缺哪一层，按已有用户授权处理，不擅自扩大范围。

这段说明不额外授权任何项目，也不修改真实项目文件；实际范围以用户交代的任务和已保存的项目政策为准。
